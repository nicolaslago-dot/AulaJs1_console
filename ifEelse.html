ETAPA 01 · CONDICIONAIS

O que são condicionais?

Condicionais permitem que o programa tome decisões de acordo com uma situação. A condição sempre resulta em true (verdadeiro) ou false (falso).

1

if

Executa o bloco quando a condição é verdadeira.

2

else if

Verifica outra condição se a anterior for falsa.

3

else

Executa uma alternativa quando nenhuma condição anterior for verdadeira.

Exemplo: vidas do jogador

Vamos verificar quantas vidas o jogador possui e mostrar uma mensagem.

let vidas = 5;

if (vidas >= 10) {
    console.log("Vida cheia!");
} else if (vidas > 0) {
    console.log("Jogador machucado!");
} else {
    console.log("Game Over!");
}

Experimente alterar o valor de vidas para 10, 5 e 0.

ETAPA 02 · OPERADORES RELACIONAIS

Como comparar valores

Os operadores relacionais comparam dois valores. O resultado da comparação é sempre true ou false.

Operador Significado Exemplo Resultado
> Maior que 10 > 5 true
< Menor que 3 < 5 true
>= Maior ou igual 18 >= 18 true
<= Menor ou igual 5 <= 10 true
=== Igual em valor e tipo 5 === 5 true
!== Diferente em valor ou tipo 5 !== 3 true
Atenção: um sinal de igual (=) atribui um valor. Três sinais (===) comparam valor e tipo.

Exemplo: comparação de idade

let idade = 18;

console.log(idade >= 18);
console.log(idade === 18);
console.log(idade !== 18);

ETAPA 03 · OPERADORES LÓGICOS

Como combinar condições

Operadores lógicos combinam ou invertem condições dentro do programa.

E (&&)

Todas as condições precisam ser verdadeiras.

No teclado ABNT2: pressione Shift + 7 duas vezes.

OU (||)

Pelo menos uma das condições precisa ser verdadeira.

No teclado ABNT2: pressione Shift + a tecla com | (geralmente ao lado do Z) duas vezes.

NÃO (!)

Inverte o resultado de uma condição.

Exemplo 1: operador E

Para entrar no evento, a pessoa precisa ter 18 anos ou mais e possuir ingresso.

let idade = 18;
let temIngresso = true;

if (idade >= 18 && temIngresso) {
    console.log("Entrada permitida!");
} else {
    console.log("Entrada negada!");
}

Exemplo 2: operador OU

Uma pessoa pode entrar se for aluno ou professor.

let aluno = true;
let professor = false;

if (aluno || professor) {
    console.log("Pode entrar!");
} else {
    console.log("Acesso negado!");
}

Exemplo 3: operador NÃO

Vamos verificar se o jogador não está bloqueado.

let bloqueado = false;

if (!bloqueado) {
    console.log("Jogador liberado!");
} else {
    console.log("Jogador bloqueado!");
}

ETAPA 04 · EXEMPLOS PRÁTICOS

Regras simples em código

Veja como as condições podem resolver situações do dia a dia.

Sistema de notas

O programa verifica a nota e informa o resultado do estudante.

let nota = 6;

if (nota >= 7) {
    console.log("Aprovado!");
} else if (nota >= 5) {
    console.log("Recuperação!");
} else {
    console.log("Reprovado!");
}

Experimente as notas 3, 5, 7 e 10.

Moedas do jogador

O jogador só pode comprar o item quando possui moedas suficientes.

let moedas = 50;
let preco = 30;

if (moedas >= preco) {
    console.log("Compra realizada!");
} else {
    console.log("Moedas insuficientes!");
}

Altere a quantidade de moedas e observe o resultado.

ETAPA 05 · EXERCÍCIOS PRÁTICOS

Agora é sua vez

Construa pequenos programas usando condicionais e operadores lógicos.

EXERCÍCIO 1

Vida do jogador

Crie uma variável chamada vida.

  • Se a vida for maior que zero, mostre “Jogador vivo”.
  • Caso contrário, mostre “Game Over”.

EXERCÍCIO 2

Classificação

Crie uma classificação de pontuação usando if, else if e else.

  • Menos de 50 pontos: Bronze.
  • De 50 até 99 pontos: Prata.
  • 100 pontos ou mais: Ouro.

EXERCÍCIO 3

Entrada no evento

Crie as variáveis idade e temIngresso. Use o operador E (&&) para liberar a entrada somente quando a pessoa tiver 18 anos ou mais e possuir ingresso.

Revisão da aula

  • if verifica uma condição.
  • else if verifica outra possibilidade.
  • else executa uma alternativa.
  • Operadores relacionais comparam valores.
  • Operadores lógicos combinam condições.

Como testar os códigos?

  1. Abra a página no navegador.
  2. Pressione F12 e entre na aba Console.
  3. Veja os resultados dos exemplos executados por js/script2.js.
  4. Altere os valores nesse arquivo e atualize a página para testar novamente.

Os exemplos aparecem no Console do navegador; eles não alteram o conteúdo visível da página.
