COMEÇO

Programação client-side

Client-side é o código executado no dispositivo do usuário. Em uma página web, o navegador carrega o JavaScript e executa suas instruções.

1

HTML carrega

A tag <script> aponta para o arquivo JavaScript.

2

Navegador executa

As instruções são lidas na ordem em que aparecem.

3

Console mostra

Mensagens, valores, cálculos e erros aparecem no console.

Ligação do JavaScript ao HTML:

<script src="js/script.js"></script>

ÁREA DE TESTES

Console e console.log()

Abra o console com F12 e escolha a aba Console. O comando console.log() mostra um conteúdo nessa área.

console.log("Olá, JavaScript!"); console.log(10); console.log(5 + 3); > Olá, JavaScript! > 10 > 8

GUARDANDO DADOS

Variáveis e constantes

Uma variável guarda um valor para usarmos depois. O nome da variável ajuda a entender o que aquele valor representa.

let

Valor que pode mudar

let pontos = 10; console.log(pontos); pontos = 20; console.log(pontos);

const

Valor que não será trocado

const nomeDoJogo = "Arena JS"; console.log(nomeDoJogo);
Regra simples: use const quando o valor não será trocado. Use let quando o programa precisar alterar o valor.

TIPOS DE DADOS

String, number e boolean

O tipo indica qual espécie de informação uma variável está guardando.

String

Texto escrito entre aspas.

const nome = "Lia";

Number

Número inteiro ou decimal, sem aspas.

const idade = 16; const preco = 29.90;

Boolean

Valor lógico: verdadeiro ou falso.

const estaLogado = true; const terminou = false;
console.log(nome); console.log(idade); console.log(estaLogado);

CÁLCULOS

Operadores

Operadores permitem calcular valores e fazer comparações.

Operador Operação Exemplo Resultado
+ Soma 10 + 5 15
- Subtração 10 - 5 5
* Multiplicação 10 * 5 50
/ Divisão 10 / 5 2
% Resto da divisão 10 % 3 1
>= Comparação idade >= 18 true ou false

DEMONSTRAÇÃO

Pequenos programas

Cada programa recebe valores, realiza uma operação e mostra o resultado.

Nome e idade

const nome = "Ravi"; let idade = 15; const idadeNoProximoAno = idade + 1; console.log(nome); console.log(idadeNoProximoAno);

Total da compra

const preco = 25; const quantidade = 3; const total = preco * quantidade; console.log(total);

Verificação de idade

const idade = 19; const maiorDeIdade = idade >= 18; console.log(maiorDeIdade);
