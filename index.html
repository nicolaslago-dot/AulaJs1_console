Como o HTML encontra o JavaScript?

A página carrega o arquivo js/script.js para que o navegador execute os comandos.

PAINEL SECRETO

O console do navegador

O console mostra mensagens, resultados e erros do JavaScript. Nesta aula, ele será nossa área de testes.

  1. Abra esta página no navegador.
  2. Pressione F12 ou Fn + F12.
  3. Clique na aba Console.
  4. Atualize a página depois de salvar o JavaScript.

MODO PRÁTICA

Missões no arquivo script.js

Edite somente js/script.js. Salve, atualize a página e confira cada resultado no console.

25 min

Missão 1: seu perfil

  1. Mostre seu nome.
  2. Mostre sua turma.
  3. Mostre um jogo, esporte, música ou série de que você gosta.

30 min

Missão 2: pontos

  1. Mostre o número 100 sem aspas.
  2. Mostre o resultado de 50 + 25.
  3. Compare "50 + 25" com 50 + 25.

35 min

Missão 3: ficha gamer

Crie cinco linhas: título, nome, turma, algo de que gosta e encerramento.

15 min

Chefe final

Crie uma tela de vitória com pelo menos cinco console.log(). Use texto, número e uma conta simples.

CHECKPOINT

Revisão rápida

  • JavaScript é uma linguagem de programação.
  • A página HTML carrega o arquivo JavaScript.
  • O console mostra o resultado das instruções.
  • console.log() envia um conteúdo para o console.
  • Texto usa aspas. Uma conta simples fica sem aspas.
