# Aula de JavaScript — Console e fundamentos da programação

Este projeto foi criado para ensinar os primeiros conceitos de JavaScript no navegador, com foco em console, variáveis, tipos de dados, operadores e lógica básica.

## O que aprendemos

- Como JavaScript funciona no ambiente do navegador
- A diferença entre programação client-side e código que roda no servidor
- Como usar o `console.log()` para mostrar informações no console do navegador
- Como declarar variáveis com `let` e `const`
- Como alterar valores em variáveis e quando usar cada tipo de declaração
- Os principais tipos de dados: `string`, `number` e `boolean`
- Como usar operadores matemáticos e de comparação
- Como testar pequenos trechos de código e observar resultados em tempo real
- Como estruturar exercícios simples para entender lógica de programação

## Conteúdos principais

### 1. Console e JavaScript no navegador

Aprendemos que o JavaScript pode ser executado pelo navegador e que o console é uma ferramenta muito útil para ver mensagens, valores e erros.

```javascript
console.log("Olá, JavaScript!");
```

### 2. Variáveis e constantes

Usamos `let` para valores que podem mudar e `const` para valores fixos.

```javascript
let pontos = 10;
pontos = 20;

const nomeDoJogo = "Arena JavaScript";
```

### 3. Tipos de dados

Entendemos que cada valor tem um tipo:

- `string`: texto
- `number`: número
- `boolean`: verdadeiro ou falso

```javascript
const nome = "Lia";
const idade = 16;
const estaLogado = true;
```

### 4. Operadores

Exploramos operações como soma, subtração, multiplicação, divisão e comparações.

```javascript
console.log(10 + 5);
console.log(idade >= 18);
```

## Objetivo da aula

A ideia foi introduzir a lógica de programação de maneira prática e visual, mostrando que o código pode receber dados, processá-los e devolver resultados imediatos.

## Exercícios trabalhados

- Criar mensagens com `console.log()`
- Declarar e alterar variáveis
- Guardar nome, idade e pontos em variáveis
- Fazer cálculos simples
- Comparar valores com operadores
- Montar fichas e pequenos programas de exemplo

## Como abrir o projeto

1. Abra a pasta do projeto no VS Code.
2. Abra o arquivo `index.html` no navegador.
3. Pressione `F12` e vá para a aba `Console`.
4. Observe os resultados dos exemplos e dos exercícios.

## Conclusão

Ao final da aula, os alunos aprenderam a: pensar em dados, guardar informações em variáveis, usar tipos corretos, realizar cálculos, testar condições e entender como o JavaScript reage em tempo real no navegador.

Esses conceitos são a base para qualquer projeto web e para os estudos futuros em programação.
